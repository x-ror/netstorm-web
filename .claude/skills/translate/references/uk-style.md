# Українська: типові помилки перекладу

Тут зібрано помилки, яких модель найчастіше припускається в українській. Кожен рядок має вигляд «погано → добре».
Не знаєш, чи слово русизм? Перевір на [r2u.org.ua](https://r2u.org.ua). Відмінювання й наголос дивись на [goroh.pp.ua](https://goroh.pp.ua).

## Русизми та кальки слів

- приймати участь → брати участь; приймати міри → уживати заходів
- на протязі дня → протягом дня; на протязі (вітер) — тільки про протяг
- слідуючий → наступний; слідувати за → іти за, стежити за
- являтися (бути) → бути; є
- співпадати → збігатися; співпадіння → збіг
- вірно (правильно) → правильно; «вірний» лише в значенні «відданий»
- міроприємство → захід; учбовий → навчальний; любий (будь-який) → будь-який
- відноситися до → стосуватися, належати до, ставитися до
- получати → отримувати, одержувати; ложитися → лягати
- самий кращий → найкращий; більш кращий → кращий
- даний (цей) → цей; являючийся → що є
- рахувати (вважати) → вважати; «рахувати» тільки про лічбу
- бувший → колишній; ведучий → провідний (або ведучий — тільки людина-ведучий)
- в якості → як; на рахунок → щодо
- тим не менше → проте, однак, але
- приходиться → доводиться; удобно → зручно
- кидатися в очі → впадати в око

## Синтаксис

- **Активні дієприкметники на -учий/-ючий/-ачий/-ячий** → підрядне речення: працюючий механізм →
  механізм, що працює; оточуючі → навколишні, ті, хто поруч. Допустимі усталені прикметники: «колючий», «сидячий».
- **Пасив з орудним відмінком діяча** → активна форма: острів був знищений ворогом → ворог знищив острів.
  Безособова форма на -но/-то без діяча — природна: «острів знищено».
- **«По» замість інших відмінків:** по причині → через; по понеділках → щопонеділка; по наказу → за наказом;
  по черзі — гаразд; іти по дорозі → іти дорогою; по-перше — гаразд.
- **Прийменники:** згідно чого → згідно з чим; відповідно до (не «відповідно з»); у випадку → у разі;
  на протязі → протягом; при допомозі → за допомогою; при нагоді — гаразд.
- **Віддієслівні іменники** → дієслово: здійснити напад → напасти; провести знищення → знищити.
- **«Який» замість «котрий»**: «котрий» лише в значенні порядку («котра година»).
- **Ступені порівняння:** найбільш сильний → найсильніший; більш сильний → сильніший.
- **Наказ:** давайте атакуємо → атакуймо; давай підемо → ходімо.

## Милозвучність (чергування)

- **у/в:** між приголосними «у», між голосними «в»: «прийшов у табір», «вона в таборі».
  На початку речення перед приголосним — «у».
- **і/й:** після голосного перед приголосним «й»: «Маркіз і Герцог», «Дощ і Грім», «жерці й воїни».
- **з/із/зі:** «із» між приголосними, «зі» перед з-, с-, ш-, щ- + приголосний: «зі зброєю», «зі Сходу»,
  «із Храму», «з острова».

## Відмінки

- **Кличний відмінок** у звертаннях: Маркізе, Герцогу, Міністре, пане Командире, друже, Володарю.
- **Давальний чоловічого роду** — переважно «-ові/-еві»: Маркізові, Принцові.
- **Родовий -а/-у:** назви предметів, будівель, стихій — частіше «-у»: Храму, Вітру, Дощу, Грому;
  особи, конкретні предмети — «-а»: жерця, Маркіза, острова.
- **Числівники:** два/три/чотири жерці, острови (називний множини); п'ять жерців;
  півтора острова; обидва жерці; двоє жерців — лише про людей.

## Правопис 2019

- проєкт, проєктор, проєкція.
- Ґ у власних назвах на місці g: Ґреллін, Ґете (допустимо й Гете — тримайся глосарію).
- «пів» у значенні «половина чогось» — окремо: пів острова, пів години, пів Німбуса;
  разом — у словах, що означають одне поняття: півострів, півкуля, північ, півфінал.
- Апостроф перед я, ю, є, ї після б, п, в, м, ф і р у кінці складу: м'ясо, п'ять, пір'я, кров'ю.
  Без апострофа, коли перед губним стоїть інший приголосний кореня (крім р): свято, цвях, тьмяний.
- Подвоєння: знання, життя, навчання, База знань (назва екрана).

## Типографіка

- Тире з пробілами: «Німбус — край вітрів».
- Дефіс без пробілів: «острів-розвідник», «будь-який».
- Апостроф `'` (у файлі вже прямий).
- Три крапки — «…» або «...» — так само, як у сусідніх рядках файлу.

## Стиль бойових брифінгів

- Короткі, рішучі наказові речення: «Знищ їхній Храм!», «Прорви оборону й визволи жерця!».
- Епіграфи звучать піднесено, архаїзми доречні («Поклади на ворога руку війни»).
- Не пом'якшуй образ і сарказм персонажів, не додавай ввічливих формул, яких нема в оригіналі.
